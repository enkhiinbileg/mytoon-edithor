# Монгол recap — хурдан горим

`Start Editor.cmd` → **Auto dub** → **Монгол recap · Хурдан горим**.

1. API keys хэсэгт орчуулгын үйлчилгээ болон ElevenLabs түлхүүрээ хадгална.
2. Доорх орчуулгын загвар, хэл, хоолой, TTS загварыг сонгоно. Эхлээд богино
   transcript-ийг хуучин Translate / Generate speech товчоор уншуулж Монгол
   дуудлагыг сонсоно. Fast горимд дууг шалгасан гэсэн сонголтыг идэвхжүүлнэ.
3. YouTube холбоос эсвэл компьютерийн видео сонгоно. Зөвхөн ашиглах эрхтэй
   эх контентоо оруулна. Хадмал байвал Import SRT / VTT-ээр оруулж, энэ видеотой
   таарч байгааг батлан Use transcript сонголтыг идэвхжүүлж болно.
4. Зэрэг үүсгэх хүсэлт (анх 2), нэг ажиллуулалтын шинэ TTS хүсэлтийн тэмдэгтийн
   дээд хязгаар (анх 120,000), шаардлагатай нэрийн толь оруулна. Энэ нь мөнгөн
   дүнгийн баталгаа биш; орчуулгын үйлчилгээ тусдаа төлбөртэй байж болно.
5. Боловсруулах товч → гарах MP4 эсвэл MKV файлын нэр сонгоно.

Дүрс, эх видеоны үргэлжлэх хугацаа хадгалагдана. Эх аудио бүхэлдээ хасагдана;
гадаад яриа болон түүнтэй холилдсон хөгжим хадгалагдахгүй. Эффект, дүрс тайрах,
шатаасан хадмал энэ хурдан экспортод орохгүй. MP4-д тохирохгүй эх codec байвал
MKV сонгож дахин ажиллуулна — амжилттай үүссэн дуу кэшээс ашиглагдана.

## Гарах файлууд

- Сонгосон замд Монгол дуутай видео.
- Тайлангийн хавтаст `recap.cutline`: эх дүрс, тус тусдаа засаж болох аудио clips.
- `transcript.json`: эх текст, орчуулга, хугацаа. Auto dub → Open saved-аар нээнэ.
- `mongolian.srt`: сонголтоор ашиглах хадмал.
- `report.json`: нийт хугацаа, шат тус бүрийн worker хугацаа, кэш, зарцуулалтын
  тоолуур, шалгах шаардлагатай өгүүлбэрүүд. Worker хугацаа зэрэг ажилласнаас
  шалтгаалан нийт хугацаанаас их байж болно.

Дуу нэг өгүүлбэрийн зайд багтахгүй бол хязгаартай хурдасгаж, нэг удаа богино
найруулгаар дахин үүсгэнэ. Дахин үүсгэлт мөн тэмдэгтийн хязгаарт тооцогдоно.
Багтаагүй хэвээр бол эцсийн видео гаргахгүй, project болон шалгах жагсаалт
хадгална. Transcript-ийг нээн засаж, зөв эх видеог сонгоод дахин ажиллуулна.

Зогсоох товч дууссан дуу, орчуулгын checkpoint-ийг хадгална. Ижил эх файл,
тохиргоогоор дахин ажиллуулбал ашиглана. API хариу нь тодорхойгүй тасарсан
төлбөртэй хүсэлтийг автоматаар давтахгүй; дахин эхлүүлэхэд уг хүсэлт дахин
тооцогдож болох тул үйлчилгээний хэрэглээг шалгана. 429 татгалзсан хүсэлтэд
хязгаартай хүлээлт, дахин оролдлого хийдэг.

## Хурд ба одоогийн хязгаар

10 минут нь зорилт, баталгаатай хугацаа биш. YouTube таталт, API дараалал,
account concurrency, CPU/GPU, засварын дахин үүсгэлтээс хамаарна. Хоёр цагийн
видеог ElevenLabs-аар бүхэлд нь боловсруулсан бодит хэмжилт хийгдээгүй.

Хадмалгүй эх дээр Whisper 120 секундийн хэсгүүдээр ажиллана. Хэсгийн зааг дахь
яриа болон нэрийн дуудлагыг сонсож шалгана. Дүрсэн дэх үйл явдлыг vision/OCR-оор
ойлгон дахин найруулах функц энэ хувилбарт байхгүй; эх ярианы хугацаагаар
дуу байрлуулдаг. ElevenLabs загвар бүр Монгол хэл ижил чанартай дэмжихгүй.

YouTube видео устсан, нэвтрэх шаардлагатай эсвэл таталтыг хязгаарласан бол
нэвтрэх хязгаарлалтыг тойрохгүй; локал видео оруулж ашиглана. Зарим видеонд
Node.js зэрэг yt-dlp-ийн дэмждэг JavaScript runtime хэрэгтэй.

## Баталгаажуулалт

- `npx.cmd tsc --noEmit`, `npm.cmd run build`.
- `node tests/fast-recap.cjs`: бодит FFmpeg, API орлуулах fixtures; дүрсний packet
  hash, аудионы байрлал, олон блокийн зааг, кэш, хязгаар, цуцлалт, project, resume.
- `node tests/fast-recap-ui.cjs`: тусгаарласан Electron profile; UI болон IPC
  орлуулсан төлбөргүй шалгалт, 1280/960 хэмжээ, таб хооронд явц хадгалах.
- Багцалсан Whisper болон base загварыг албан ёсны JFK дээжээр шалгасан.

Туршилтууд хэрэглэгчийн API түлхүүрээр төлбөртэй дуу үүсгэдэггүй.


Нэмэлт хэмжилт: 7200 секундийн жижиг дүрстэй хиймэл видео, гурван бэлэн
аудио дохио ашигласан экспорт 56.66 секундэд дууссан. Гарах хугацаа 7200.12
секунд байсан. Энэ нь зөвхөн аудио нэгтгэх ба stream-copy экспортын хэмжилт;
бодит recap-ийн таталт, яриа танилт, орчуулга, ElevenLabs ороогүй.
YouTube extraction-ийг нийтийн Big Buck Bunny видеонд download хийхгүйгээр
шалгасан. Хэрэглэгчийн бодит YouTube видеог бүтэн татах туршилт хийгдээгүй.
